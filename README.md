# Gurn

Live face filters in the browser: stickers, warps, 3D masks, colour looks, backdrops and expression triggers. Photo and video capture. Everything runs on the device.

Live at https://n-dev.github.io/gurn/ (add `#debug` for debug mode).

The whole app is `index.html`. Face tracking is MediaPipe Face Landmarker, loaded from a CDN.
